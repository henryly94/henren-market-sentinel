1. 为什么「联储只认管道不认股价」？

在通胀粘性与鹰派美联储周期下，单纯因估值收缩引发的股市下跌不会触发降息救市；只有当 SOFR 击穿 IORB 走廊上限、美债失去流动性威胁主权发债管道时，联储才会注水修管道。

2. 什么是「不是钱没了，是钱贵了」？

当隔夜回购未爆裂（SOFR 温和），但 CCC 级垃圾债收益率飙升至 15%~18% 以上而投资级（IG）利差仍低时，说明高利率正在按资产负债表质量从最脆弱的边缘高负债企业向上逐层出清。

3. 为什么负 Gamma 区间里的暴涨常是「反抽」？

指数位于 Zero-Gamma 翻转线下方时，期权做市商被迫「涨时追买期货、跌时顺势砸盘」，任何消息面利好都会被微结构挤压成单日脉冲式暴涨；只要资金成本与信用利差未改善，难以形成持续反转。

4. 为什么回购吃紧砸出的黄金回调叫「打折期」？

高杠杆基金遭遇追加保证金时遵循「先砍流动性最好资产」原则，常连带抛售黄金换取美元现金。一旦月末/年末结算大考后 TGA 放水或联储被迫扩表修管道，无对手方违约风险的黄金往往先于股票领涨。
